# Changelog

## [1.0.0-workbench] - 2026-04-26
### Added
- **Workbench Interface:** Full-viewport, dual-pane layout separating the simulation "Stage" from the interactive sidebar.
- **Guided Discovery Slideshow:** Interactive theory tab explaining the symmetric parametrization step-by-step with LaTeX rendering.
- **Milestone Presets:** One-click presets for classic Poncelet configurations (Concentric, Bicentric, Right Triangle, etc.).
- **Research Telemetry:** Real-time data panel displaying coordinate telemetry $(G, H, O, I)$ and triangle properties (Area, Perimeter).
- **Export Tools:** CSV data export for research and analysis.

### Improved
- **Mathematical Accuracy:** Centers $(O, H, N, I)$ are now calculated post-stretch, ensuring geometric precision.
- **Layout & Responsiveness:** Flexbox-based layout fixes to eliminate clipping and optimize screen real estate.
- **Theory Documentation:** Math rendering improved via KaTeX and better structured for pedagogical clarity.
